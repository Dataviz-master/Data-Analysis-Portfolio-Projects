🚗 Car Sales Dashboard (Power BI)
📊 Overview

This project presents a Car Sales Dashboard built in Power BI to analyze sales performance, trends, and key business metrics. It provides both high-level insights and detailed transaction-level data to support data-driven decision-making.

🎯 Objectives
Track Year-to-Date (YTD) and Month-to-Date (MTD) performance
Analyze sales trends over time
Understand customer preferences (body style, color, etc.)
Evaluate company and dealer performance
Provide interactive filtering for deeper insights
